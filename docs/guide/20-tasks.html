How to…

Add a company

Add a row to data/boards.csv (ats, slug, name, website, source). The next run fetches it; pipeline.logos picks up its icon.

Add a job source (a new ATS)

  1. Save a real response as tests/fixtures/<ats>_<company>.json.
  2. Write pipeline/connectors/<ats>.py with parse() and fetch(), following an existing connector.
  3. Register it in connectors/__init__.py and add a test in tests/test_connectors.py.
  4. Check the source's terms allow reuse, and credit it on the Sources page if they ask.

Add a free AI provider

If it speaks the OpenAI chat format, add one Provider(...) to compat.py and to EXTRA, its key to GitHub secrets and the workflow's env, and a pace (<NAME>_RPM). Compare its answers with Gemini's on 20 postings before relying on it.

Change a verdict rule

Edit decide() in verdict.py, add a test for the new case, run the tests, then export: every job gets the new verdict without any AI call.

Add interface text

Add the key to en and fr in i18n.ts (TypeScript will complain if French is missing) and to i18n-ar.ts, then use tr(lang, "key").

Before you push
  • uv run pytest -q and uv run ruff check . pass.
  • The site builds (npx astro build).
  • No secret in the diff. If you changed the database locally, remember CI keeps its own copy on the release.
  • Log a significant decision in docs/DECISIONS.md.
