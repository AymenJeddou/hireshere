Chapter 18Automation: the daily GitHub workflow

One YAML file runs the whole system every day on GitHub's servers: download the database, fetch, publish, classify, publish again, notify, save the database, check the live site. Here it is in full, then step by step.

{{file .github/workflows/daily.yml}}

Step by step

Encrypting the snapshot

After each run it loads the home page, the search page, /api/geo and four job pages taken from the export just made, retrying for a minute while the deploy settles. A job page served by the browser fallback is a warning (it works for visitors); a non-200 answer or "Page not found" is a failure.
