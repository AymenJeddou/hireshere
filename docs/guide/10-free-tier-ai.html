Chapter 11Running the AI on free tiers

The same extraction can be produced by several providers. Since October 2026 the owner has no AI budget, so HiresHere runs Gemini, Groq and Mistral side by side on their free tiers, each paced under its limits, all pulling from one shared queue.

Talking to Gemini (pipeline/classify/gemini.py)

This is the only file that knows Gemini's API. A request carries the system prompt, the posting, and the JSON schema; temperature 0 makes answers as repeatable as possible:

{{py pipeline/classify/gemini.py request_body}} {{py pipeline/classify/gemini.py parse_response}}

Errors are sorted carefully, because they mean different things:

{{py pipeline/classify/gemini.py _post}}
AnswerMeaningWhat the code does
429 with "PerDay" in the bodyFree daily quota used upQuotaError: this provider stops for today, the others continue.
402Prepaid credit exhaustedQuotaError as well.
Other 429, or 5xxToo fast, or a server hiccupRetry with growing waits (8, 16, 32, 60 seconds).
Other 4xxA real error with this requestModelError: this posting is marked "error" and retried on a later run.

OpenAI-compatible providers (pipeline/classify/compat.py)

Groq and Mistral both speak the OpenAI "chat completions" format, so one class serves both; each provider is just configuration:

{{py pipeline/classify/compat.py Provider}} {{py pipeline/classify/compat.py GROQ}} {{py pipeline/classify/compat.py MISTRAL}}
Failing gracefully

A provider whose account allows zero requests a minute (the Mistral case: x-ratelimit-limit-req-minute: 0), or that keeps answering 429 after every retry, raises QuotaError and leaves the run. Without this, it would mark postings as errors and take them away from the providers that work.

Three workers, one queue (runner.run_sync)

{{py pipeline/classify/runner.py run_sync}}
  • The queue is a deque (double-ended queue). Each worker takes the next job from the front with popleft().
  • On a quota error the job is put back at the front (appendleft) for another provider, and that worker stops.
  • Pacing: after each request the worker sleeps so that it never exceeds its requests per minute (Gemini 14, Groq 4, Mistral 50 in the workflow).
  • Time budget: CLASSIFY_MINUTES = 35. When it runs out, workers stop taking jobs; the rest stay pending for the next day.
  • asyncio.gather runs the workers at the same time and waits for all of them.
  • Each saved extraction records which model produced it, so results can be audited later.

The classify command

{{py pipeline/run.py cmd_classify}}

It reports what was skipped and reused, estimates tokens and cost (from the paid prices, as a reference), and runs either the free sync mode or the paid batch mode. An out-of-credit answer at batch submission does not fail the run: postings simply wait.

The paid Batch API (kept for later)

When there is a budget, batch mode is half price: the pipeline uploads one JSONL file with every request, Gemini processes it within hours, and a later step downloads the results. Each line carries a key (the content hash), because results come back keyed, not in order, and individual lines can fail while the batch succeeds.

{{py pipeline/classify/gemini.py batch_submit}} {{py pipeline/classify/runner.py collect}}
