Chapter 3The technologies, one by one

HiresHere deliberately uses few tools: the Python standard library plus two packages for the pipeline, Astro for the website, and free hosted services around them. This chapter explains what each one is and why it was chosen.

The data pipeline (Python)

TechnologyWhat it isWhat HiresHere uses it for
Python 3.12The programming language of the pipeline.Everything in pipeline/: fetching, database, AI calls, rules, export, emails.
uvA fast Python package and project manager (installs dependencies, runs commands).uv sync installs the exact versions in uv.lock; uv run python -m pipeline.run fetch runs a command inside that environment.
httpxAn HTTP client library with async support.Every network call: job feeds, Gemini, Groq, Mistral, Resend, Telegram, Cloudflare's API.
PydanticData validation with Python type hints.The Job and Board models, and above all the Extraction schema that validates every AI answer.
asyncio (standard library)Python's built-in way to run many network waits at the same time.Fetching 537 boards five at a time; running two or three AI providers in parallel.
SQLite (standard library sqlite3)A full SQL database stored in a single file.jobs.db: every job ever seen, its status, the AI extractions, the run history.
argparse, csv, json, re, hmac, html.parserStandard library modules.The command line, the board list, JSON files, regular expressions for the pre-filter and rules, unsubscribe tokens, turning HTML into text.
pytestThe test runner.75 tests, run offline against saved example feeds.
RuffA Python linter and formatter.Keeps style consistent and catches mistakes: ruff check and ruff format.
Why so few dependencies?

The owner's rule is "stdlib plus httpx and pydantic". Fewer packages means fewer updates, fewer security issues, faster installs in CI, and code a newcomer can read without learning a framework. When something can be done in a few lines with the standard library (HTML to text, HMAC, CSV), it is.

ProviderModelRole
Google Gemini APIgemini-3.1-flash-liteMain classifier. Supports a strict JSON schema for answers (responseJsonSchema) and a Batch API at half price. Used on the free tier since 2026-10-11.

The website

TechnologyWhat it isUse in HiresHere
AstroA static site generator: you write components, it outputs plain HTML at build time.Every page under site/src/pages; 2,000+ static pages built in about 20 seconds.
TypeScriptJavaScript with types.Browser scripts (search, filters, saved jobs, maps) and the shared rendering code for job pages.
CSS (no framework)Hand-written styles with custom properties (design tokens).global.css (tokens, base) and components.css (cards, pills, layouts).
FontsourceSelf-hosted web fonts as npm packages.Bricolage Grotesque (headings) and DM Sans (text), served from the site itself, not from Google Fonts.
Natural Earth + tools/world-map.mjsPublic-domain map data and a small script that turns it into one SVG.public/world.svg: one path per country, coloured in the browser by job counts or verdicts.

ServiceWhat HiresHere uses
