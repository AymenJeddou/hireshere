Chapter 1How to read this guide, and a glossary

This guide explains the whole HiresHere system in the order data flows through it: from a company's job feed to a card on the website and an email in someone's inbox. Each chapter introduces a part of the system, shows the real code, and explains why it is written that way.

You do not need to read it in one go. Chapters 2 to 4 give the map; the later chapters can be read on their own when you work on that part. Code excerpts are real: they are pulled from the repository when the PDF is built, so if you change the code and rebuild the guide, the excerpts follow.

Glossary

ATS (applicant tracking system)
The software a company uses to publish jobs and receive applications: Greenhouse, Lever, Ashby, SmartRecruiters, Workable, Recruitee, Teamtailor. Most expose a public JSON "job board" feed, which is where HiresHere reads jobs from.
Board
One company's job feed on one ATS, identified by the pair (ats, slug), for example (greenhouse, doximity). HiresHere tracks 537 of them.
Connector
A small Python module that knows how to read one ATS's feed and turn it into HiresHere's own Job objects.
Extraction
The structured answer the AI gives for one posting: remote type, allowed countries and regions, time zone window, work authorization, seniority, an evidence quote, and so on.
Verdict
The answer to "can someone living in country X apply?": eligible ("You can apply"), likely, unclear ("Ask the employer") or not_eligible (hidden). Computed by plain Python rules from an extraction, for each of 243 countries.
Content hash
A short fingerprint of a posting's title, location and description. If it does not change, the posting does not need to be read by the AI again.
Export
The step that turns the database into the JSON files the website reads.
Shard
One of 256 small JSON files holding the full details of the jobs whose slug hash starts with the same two hex characters. A job page loads only its shard.
Pages Function
A small piece of JavaScript Cloudflare runs on its servers for a specific URL, for example to build a job page on request.
D1
Cloudflare's hosted SQLite database, used for subscribers, error reports and employer requests.
Free tier
The amount of a paid service you can use without paying. HiresHere runs entirely on free tiers, which shapes many decisions.
Rate limit / quota
How many requests a service accepts per minute (rate limit) or per day (quota). Exceeding it returns HTTP 429.
Idempotent
An operation that gives the same result if you run it twice. The daily pipeline is built so that re-running it never double-counts or double-sends.
