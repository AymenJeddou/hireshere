Chapter 7Fetching jobs: HTTP, concurrency, connectors

The fetch step downloads the public job feeds of 537 boards in about a minute, turns each into a list of Job objects, and applies the diff rules. It must be fast, polite to the companies' servers, and robust to any feed failing.

A polite HTTP client (pipeline/http.py)

{{py pipeline/http.py get_json}}
  • Retries with backoff. A timeout, an HTTP 429 (too many requests) or a 5xx server error is often temporary, so it is retried after 2, then 4 seconds (2**attempt). A 4xx error such as 404 is not retried: the board really does not exist.
  • One error type. Every failure becomes a FetchError, so the caller has one thing to catch and a short message to store in boards.last_error.
  • The client itself (make_client) sets the honest User-Agent, the timeout and follow_redirects.

Five at a time (pipeline/run.py)

{{py pipeline/run.py fetch_board}} {{py pipeline/run.py fetch_all}}
asyncio in three sentences

Most of fetching is waiting for servers to answer. With asyncio, a single Python thread starts a request, and while waiting it starts others. A semaphore is a counter that lets at most N tasks inside a block at once (here five), and as_completed hands back each board's result the moment it finishes, so the database is updated while other downloads are still running.

fetch_board never lets an exception escape: a broken feed becomes a FetchResult(ok=False), which rule 3 handles (no expiry) and rule 5 counts (retire after five).

The fetch command

{{py pipeline/run.py cmd_fetch}}

It returns a Markdown report. Every command does this, and main() appends the report to $GITHUB_STEP_SUMMARY, so each workflow run shows a readable summary page on GitHub.

Connectors: one module per source

Each connector exposes two functions: parse(data, board), a pure function that turns the feed's JSON into Job objects (easy to test with saved example feeds), and async fetch(client, board), which downloads and calls parse. A registry maps the ATS name to its module:

{{file pipeline/connectors/__init__.py}}

Greenhouse

{{py pipeline/connectors/greenhouse.py parse}}

Greenhouse returns all jobs with ?content=true. Its descriptions are HTML that is itself entity-escaped (&lt;p&gt;), hence html_to_text(..., escaped=True). Optional metadata (employment type) is read with a small helper. first_published becomes posted_at.

Lever

{{py pipeline/connectors/lever.py parse}}

Lever gives a plain-text description plus "lists" (Requirements, What you'll do) and a salary range. workplaceType (remote, hybrid, onsite) becomes remote_flag_raw, which the pre-filter uses. createdAt is a Unix time in milliseconds.

Ashby

{{py pipeline/connectors/ashby.py parse}}

Ashby has a secondary-locations list and structured compensation. Unlisted jobs are skipped.

SmartRecruiters: pagination

{{py pipeline/connectors/smartrecruiters.py fetch}}

SmartRecruiters returns 100 postings per page and no description in the list. The connector pages through all of them (needed so expiry is correct) but stops at 10 pages: bigger boards are large on-site employers and a poor fit.

Workable, Recruitee, Teamtailor

Workable's public widget API returns every job with its description in one request; Recruitee's offers API has explicit remote/hybrid/on-site flags; Teamtailor publishes a JSON Feed whose items carry a schema.org JobPosting, including jobLocationType: TELECOMMUTE for remote jobs.

{{py pipeline/connectors/teamtailor.py parse}}

Remote OK and Jobicy: job boards with terms

These are not company systems but public job boards whose API terms allow reuse with a credit and a link back. Their apply_url is the board's own page, and the site names them as the source. Jobicy's feed only covers the last 7 days and pages with a cursor:

The legal line

HiresHere only reads feeds a company publishes for its own careers page, or board APIs whose terms allow reuse. It never scrapes LinkedIn, Indeed, Glassdoor or any site whose terms forbid it, and never republishes full descriptions on the website (only short quotes and fields). Remotive and Himalayas were left out because their terms ask not to feed other job sites.
